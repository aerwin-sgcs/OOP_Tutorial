Installing pygame

Pygame is the library that gives Ironwall its window, images and animation. You only need to install it once. These steps are for macOS.

STEP 1

Open the Terminal

Press Cmd + Space, type Terminal, and press Enter. A black window opens where you can type commands. (You can also use the Terminal built into PyCharm — the tab at the bottom of the window.)

STEP 2

Check you have Python 3

Type this and press Enter:

python3 --version

You should see a version number of 3.10 or higher, like:

Python 3.13.0

If you get an error instead, install Python from python.org/downloads first, then come back.

STEP 3

Install pygame

Type this and press Enter:

pip3 install pygame

You will see some text scroll past as it downloads. When it finishes you should see a line containing:

Successfully installed pygame-2.6.1
STEP 4

Check it worked

Type this and press Enter:

python3 -m pygame.examples.aliens

If a little game window pops open, pygame is installed correctly. Close the window — you are ready to run Ironwall.

Now you can run your game with python3 ironwall_visual.py, or play the finished game from the Ironwall page.

If something goes wrong

pip3: command not found
Try python3 -m pip install pygame instead.
It says permission denied
Try pip3 install --user pygame — this installs it just for your account.
It installed, but Ironwall says "No module named pygame"
You may have more than one Python. Run the game the same way you installed: if you used python3, run with python3 too.
Still stuck?
Show your teacher the exact red error message — that is the fastest way to fix it.
